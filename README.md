# Bekeric Enemies
 デコンパイルや難読化解除の方法が分からないという方でもソースコードを見られるようにするためのリポジトリです。  
 それ以外の目的は特にありませんのでご注意下さい（^A^;）  

 このModの配布場所：https://www.curseforge.com/minecraft/mc-mods/bekeric-enemies  
 ※マイクラのバージョンは1.12.2にする必要があります。  
 #
 バージョン1.1.2  
 無敵化解除剣の3行目の説明文を追加  
 ・無敵時間中のウィザーを倒せないという説明を追加  
 無敵化解除のクワ・改を追加  
 ・読み込み範囲内の無敵化したMOBまたはHP∞のMOBを処理する  
 ・無敵化解除のクワとは異なり普通のMOBは倒さない  
 無敵化解除弓を追加  
 ・無敵化バグが発生したMOBにも矢が当たる弓  
 ・矢がインベントリに無くても使える  
 ・矢の速さは通常の矢の2倍でブレは無い  
 ・MOBを倒すための弓だがアイテムや経験値オーブも倒してしまう  
 ・自分自身を倒すことはできない  
 消滅の剣を追加  
 ・エンティティを消すことができる剣  
 ・無敵化解除剣と同様に無敵時間中のウィザーには効かない  
 ・エンダードラゴンはkillコマンドとシ亡時の演出短縮で無理矢理消す  
 消滅の弓を追加  
 ・エンティティを消すことができる弓  
 ・矢がインベントリに無くても使える  
 ・矢の速さは通常の矢の2倍でブレは無い  
 ・無敵化解除弓と同様に無敵化したMOBにも当たる  
 ・アイテムや経験値オーブなど生物以外にも当たる  
 ・エンダードラゴンはkillコマンドとシ亡時の演出短縮で無理矢理消す  
 ・自分自身を倒すことはできない  
 消滅のクワを追加  
 ・エンティティを消すことができるアイテム  
 ・アイテムや経験値オーブなど生物以外も消すことができる  
 ・エンダードラゴンはkillコマンドとシ亡時の演出短縮で無理矢理消す  
 
 バージョン1.1.1  
 無敵化解除のクワを追加  
 ・右クリックすると読み込み範囲内のすべてのMOBのHPを0にし、無敵化している場合は解除する  
 ・これで奈落の底に落ちた動物も処理できる  
 ・自分自身には効かないようにしている  
 無敵化解除剣のレシピを改善  
 ・中央に置く必要が無くなった  

 バージョン1.1

 無敵化解除の瓶を追加  
 ・無敵化バグが発生したプレイヤーを処理できる食料  
 ・keepInventoryがfalseの状態で使うと全ロスするため要注意
