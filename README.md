# Bekeric Enemies
 デコンパイルや難読化解除の方法が分からないという方でもソースコードを見られるようにするためのリポジトリです。  
 それ以外の目的は特にありませんのでご注意下さい（^A^;）  

 このModの配布場所：https://www.curseforge.com/minecraft/mc-mods/bekeric-enemies  
 ※マイクラのバージョンは1.12.2にする必要があります。  
 #
 バージョン1.1.1  
 無敵化解除のクワを追加  
 ・右クリックすると読み込み範囲内のすべてのMOBのHPを0にし、無敵化している場合は解除する  
 ・これで奈落の底に落ちた動物も処理できる  
 ・自分自身には効かないようにしている  
 無敵化解除剣のレシピを改善  
 ・中央に置く必要が無くなった  

 バージョン1.1  
 無敵化解除剣を追加  
 ・無敵化バグが発生したMOBを処理できるダイヤ剣  
 無敵化解除の瓶を追加  
 ・無敵化バグが発生したプレイヤーを処理できる食料  
 ・keepInventoryがfalseの状態で使うと全ロスするため要注意  
 #
